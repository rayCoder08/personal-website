View Branchseed Navigator on GitHub

Branchseed Navigator

Aorta Segmentation

Our four-person team built a CPU-only pipeline in 24 hours to find the daughter vessels branching from a supplied abdominal aorta mask in CTA scans.

First place, healthcare track · Battle of the Schools

Tech Stack
Python, NumPy, SciPy, SimpleITK, Node.js
Implementation
The pipeline restricts its search to a narrow physical shell around the aorta, then traces the first 5–10 mm of each candidate branch. It preserves the scan’s physical coordinates and runs under a four-core CPU and 8 GB RAM limit.

Input CTA slice from the subject001 NIfTI test case.

View Coin Counter on GitHub

Computer Vision Coin Counter

A Raspberry Pi counter that identifies five Canadian coin denominations, annotates the detections, and calculates their total value.

Tech Stack
Python, OpenCV, NumPy, Raspberry Pi 3
Implementation
I used Gaussian blur and Hough circles to localize coins, then grouped detections across 19 frames. Calibrated radii and inner-versus-outer colour distinguish the similarly sized loonie and toonie.
View Piano Tiles on GitHub

Piano Tiles Hardware Game

I built a timing game with a partner. A Tkinter interface responds to four physical buttons wired through a breadboard to a Raspberry Pi.

Tech Stack
Python, Tkinter, gpiozero, Raspberry Pi
Implementation
I wired the controls and piezo buzzer. Debounced GPIO inputs drive the game loop, and the buzzer plays distinct feedback for hits and misses.

About me

I’m a first-year Computer Science student at the University of Waterloo. I’m interested in software engineering that makes complex systems easier to understand, especially in aviation and autonomous vehicles.

I like building things that respond to the real world. Working with computer vision, Raspberry Pis, and motion sensors means testing real inputs and figuring out what breaks outside a demo.

I also built the website for my high school’s game development club, including a showcase of nine student-built games.
