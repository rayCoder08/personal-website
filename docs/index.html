Aerochronix

An aviation safety platform for exploring documented incidents, comparing contributing factors, and replaying recorded flight paths.

Technology
React, TypeScript, D3.js, Three.js
Implementation
The graph progressively renders connected incidents and factors. Selecting a node reveals the supporting investigation evidence.

Candybal

A two-player Unreal Engine game that turns iPhones into tilt controllers for a cupcake brawl.

Technology
Unreal Engine 5, C++, Node.js, WebSocket, Cloudflare Tunnel
Implementation
I designed the periodic sunlight mechanic. It melts both players’ frosting, adding pressure to change tactics before the round ends.
GitHub

Casentra

Corporate Collapse Simulator

A historical simulation that puts players in charge of decisions at companies such as Enron and Silicon Valley Bank, then compares their choices with the record.

Technology
React, TypeScript, Vite, Netlify Functions
Implementation
A deterministic engine replays choices and updates each scenario. Interview Mode grades calculations and supports optional AI feedback.
Live demo

Branchseed Navigator

Aorta Segmentation

A CPU-only prototype that starts with an aorta mask and traces the first 5–10 mm of the blood vessels branching from it in CT and CTA scans.

Technology
Python, NumPy, SciPy, SimpleITK, Node.js
Implementation
Our four-person team built the prototype in 24 hours under a four-core CPU and 8 GB RAM limit. It placed first in the Battle of the Schools healthcare track.

Input CTA slice from the subject001 NIfTI test case.

Computer Vision Coin Counter

A Raspberry Pi application that identifies Canadian coins, labels the detections, and totals their value.

Technology
Python, OpenCV, NumPy, Raspberry Pi 3
Implementation
I combined Hough circle detection with radius and colour calibration, then aggregated detections across frames to reduce false readings.
GitHub

Piano Tiles Hardware Game

A timing game played with four physical push buttons connected to a Raspberry Pi.

Technology
Python, Tkinter, gpiozero, Raspberry Pi
Implementation
I wired the physical controls. Four debounced GPIO inputs drive the game loop, and a piezo buzzer signals hits and misses.
GitHub
